# SEDS-Solar-Sail-C-DH-PCB
Spacecraft avionics architecture, component selection, subsystem interfaces, and electrical system design

Solar Sail C&DH Board

I am currently working on the Command and Data Handling (C&DH) subsystem for the Texas A&M SEDS Solar Sail project.

My responsibilities include developing the preliminary PCB architecture, identifying key components, and defining electrical interfaces between the C&DH board and other spacecraft subsystems, including power distribution, communications, and attitude determination and control.

This project has introduced me to spacecraft-level electrical integration, where board designs must account for communication interfaces, power requirements, sensor connections, and compatibility with other subsystems.

**Current status:** Preliminary board architecture and component planning.
